# Futuro Dev — Gerador de Crachá

## Sobre
Site para a Feira de Profissões. Dá para personalizar um crachá com nome, área de TI, cor e avatar.

## Como usar
1. Abra `index.html` no navegador.
2. Digite seu nome e escolha uma área de TI.
3. Escolha uma das dez cores e um avatar.
4. O crachá e o exemplo de código mudam na tela.
5. Clique em **Modo foto** para destacar o crachá.
6. Clique em **Voltar / reiniciar** para voltar e limpar as escolhas.

## Tecnologias
HTML, CSS e JavaScript puro.

## Arquivos
- `index.html`: estrutura da página.
- `style.css`: visual e adaptação para celular.
- `script.js`: atualiza o crachá.

## Publicação
Envie os arquivos para um repositório no GitHub e habilite GitHub Pages nas configurações.
